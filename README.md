📌 Note for Developers: Please switch to the code-of-the-project branch to view and access the full source code.🧪 Water Sort PuzzleInteractive, Addictive, & Browser-Based Color Sorting Puzzle Game🌐 Live Demo • ✨ Features • 🛠️ Tech Stack • 🚀 Quickstart📌 OverviewWater Sort Puzzle is a lightweight, high-performance web application deployed on Netlify that provides an engaging and challenging color-sorting puzzle experience right in your browser.Unlike standard fixed-level games, Water Sort Puzzle features Infinite Dynamically Generated Levels with smoothly scaling difficulty. It operates with 100% Client-Side Processing, meaning there is zero lag, no server calls needed, and instant loading times.✨ Key Features🧪 Infinite Level Generation: Procedurally generated levels that automatically adjust color variety and difficulty as you progress.🎨 Glassmorphism Visuals: Sleek frosted-glass tube aesthetics, vibrant liquid colors, and fluid pour animations.↩️ Undo & Restart Controls: Instantly revert accidental moves or reset the current puzzle state when stuck.📱 Cross-Device Responsive: Works seamlessly across mobile screens, tablets, and desktop browsers.⚡ 100% Offline Capable: Runs completely inside your browser with zero network latency.🎮 How to PlayOrganize all colors into separate tubes to win!Select a Tube: Click or tap any test tube to pick up the top layer of liquid.Pour the Liquid: Click another tube to pour the liquid in.Pouring Rules:You can only pour into a tube if it has enough empty space.You can only pour liquid onto the same color (or into an empty tube).Objective: Sort the liquids until every non-empty tube contains only one solid color.🛠️ Tech Stack & DependenciesWater Sort Puzzle relies on modern native web technologies to deliver high performance directly in the browser:CategoryTechnologies / Libraries UsedFrontend CoreHTML5, CSS3, JavaScript (ES6+)Styling & DesignGlassmorphism CSS, Responsive Flexbox LayoutsFonts & IconsGoogle Fonts (Inter API), SVG Vector GraphicsDeployment & HostingNetlify🚀 Getting StartedFollow these steps to run the project locally on your machine:PrerequisitesAny modern web browser (Chrome, Firefox, Edge, Safari)A simple HTTP server (such as VS Code Live Server, Python http.server, or Node.js http-server)InstallationClone the repository:git clone https://github.com/your-username/water-sort-game.git
